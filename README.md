# Clayton Hall Academy iPad Repair Pilot updates

This public repository holds approved, signed Android APK release assets and `latest.json` for the pilot app's optional update prompt. Source code, Jamf inventory, user data and signing keys are kept in the private project repository.

The app checks the version file at most once per day and opens the GitHub release download in the user's browser. Android asks the user to approve installation; updates are never installed silently.
